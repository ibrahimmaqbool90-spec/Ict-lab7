# Temperature Converter

## Purpose
A small Python program that converts a temperature from Celsius to Fahrenheit and Kelvin. Made for practising Git and GitHub.

## How to Run
python storage_estimator.py

## Example
Input:  Temperature in Celsius: 25
Output: Fahrenheit: 77.0 °F
        Kelvin: 298.15 K
